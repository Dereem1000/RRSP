Platform Capabilities

Core strengths built into this AutoM demo — connected data, expiry tracking, billing, access control, and productivity tools.

Modular Admin Workspace

Ten admin modules plus customer portal — dashboard, vehicles, inspections, insurance, accounts, clients, documents, support, team, and settings.

  • Category-specific compliance forms and reference fields
  • Portal and staff profile moderation workflows
  • Company branding on admin and portal auth surfaces
  • Role-aware sidebar — each user sees only permitted modules

One Platform, Connected Data

Vehicles, clients, inspections, insurance, and compliance share one data model — enter once, visible everywhere.

  • Client link-tree across person docs and fleet
  • Vehicle tied to inspection, insurance, certified copy
  • Deep links from search and profile context
  • Renewal history preserved — not overwritten silently

Expiry Intelligence

Dashboard surfaces what's expiring soon across ten categories with configurable windows per user.

  • Near-expiry counts and sortable table
  • Windows: 7 days through 1 year per category
  • Document life bars with color-coded segments
  • Renewal shortcuts from dashboard and lists

Billing Transparency

Wallets, payment requests, and charge confirmation dialogs shared across inspections and policies.

  • Wallet-first allocation with outstanding shown
  • Line-item surcharges and fees itemized
  • Charge preview before any save or send
  • One-time fees for non-directory names

Role-Based Access

Five roles with an editable per-module permission matrix in Settings → Accounts.

  • Admin, manager, inspector, provider, client
  • Provider-scoped insurance views
  • Portal moderation for profile changes
  • Separate staff and client auth surfaces

Productivity & Intelligence

Cross-module tools included in this demo.

  • Universal search (Ctrl+K) with pin-to-board
  • OCR scan-to-form on permits and certificates
  • Standing scores and client status flags
  • Prefetching navigation for instant page loads

Admin Experience — Shell & Navigation

A cohesive workspace — role-aware sidebar, universal search, pin board dock, and consistent split layout (form + live document preview) across modules.

Universal Search

Jump to clients, vehicles, compliance records, inspections, or policies from anywhere. Filter by type and pin results to the side board.

Pin Board Dock

Keep document previews open beside forms — compare a scan while entering data. Auto-expiry timer and search-to-pin.

Split Module Layout

Form on the left, live preview on the right — consistent across clients, compliance, inspections, and insurance.

Operational Awareness

Update banners, database health warnings, blacklisted-client notices, and in-app changelog with unseen-version indicator.

Module Guide

Each section maps to a live area in this demo. Use the Live Demo button on each page to walk through the real interface.

Dashboard

Operational command center with expiry status cards across ten categories, configurable windows, sortable expiring-soon table, and role-specific home views for inspectors and providers.

  • Near-expiry counts: permits, IDs, inspection, insurance, and more
  • Per-category expiry presets persisted per user
  • Quick add client and assignment cards with renewal shortcuts
  • Mobile toggle between status cards and expiring list

Vehicles

Central fleet registry with plate, VIN, make, model, registered vs current owner, and cross-module status for inspection, insurance, and certified copy.

  • Searchable list with model age display from year
  • OCR from certified copy to populate vehicle fields
  • Client–vehicle linking and duplicate certified-copy guard
  • Technical fields: fuel type, engine CC, tare, MGW, tire size

Inspections

End-to-end inspection lifecycle: create, renew, attach hard-copy uploads, OCR scan autofill, and Save & charge with wallet preview dialog.

  • Status workflow: pending, in progress, pass, failed
  • Inspector combobox with garage and VTS defaults
  • Terms: 6 weeks, 1 year, 2 years — expiry auto-calculated
  • Front, back, sticker photo, and sticker scan upload slots

Insurance

Policy administration for brokers and providers — coverage types, flexible policy holders, seven auto-suggested surcharge lines, and Save & send charge flow.

  • Bill registered owner, linked client, or free-text holder
  • Provider role with insurance-focused dashboard
  • Surcharges: engine size, owner mismatch, under 25, and more
  • Renewal flow with collapsible prior-term history

Clients

Deep client directory — not a simple contact list. Standing scores, link-tree visualization, portal moderation, and wallet on the same profile.

  • JSD reference, status filters, and standing flag icons
  • Person-level compliance plus per-vehicle document cards
  • Visual link-tree: person docs → vehicles → compliance
  • Portal provisioning, upload moderation, welcome email resend

Documents / Compliance Hub

Ten expiry-tracked categories — each with tailored forms, reference numbers, renewal history, OCR scan autofill, and document life bars.

  • Driver's permit, national ID, passport, taxi badge, defensive driving
  • Inspection, insurance, certified copy, tint exemption, battery warranty
  • National ID dual-sided front/back upload slots
  • Feeds dashboard expiry cards and expiring-soon table

Accounts & Payments

Unified billing ledger across insurance and inspections with wallet-first allocation and transparent charge confirmation before any debit.

  • Payment requests: draft → sent → paid → cancelled
  • Line-item breakdown: premium, surcharges, and fees
  • Admin wallet top-up and color-coded balance display
  • Client wallet section on profile ties into charge flows

Support

Built-in messaging — per-client conversation threads, floating admin inbox, and portal chat widget for end customers.

  • Unread badges on inbox nav and floating button
  • Full thread view with client context
  • Portal messages page plus floating chat on other pages
  • Support contact block configurable in settings

Customer Portal

Separate branded experience for vehicle owners and fleet clients — onboarding, dashboard, account, and messages.

Portal Dashboard & Account

First-login onboarding, vehicle picker with coverage cards, wallet balance, outstanding payment requests, and profile changes submitted for staff approval.

  • Coverage cards with document life bars per vehicle
  • Linked team-shared records and client uploads when enabled
  • Full wallet view, transaction history, and top-up
  • Messages page and floating support chat
